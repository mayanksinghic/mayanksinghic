## What I do

- **LLM and agent evaluation.** Compare model responses on quality dimensions. Check claims against tool-call traces. Write rationales that quote the exact words behind each score.
- **RLHF and adversarial prompts.** Write prompts that break models, then rate and rank the outputs.
- **Review.** Grade other contributors' tasks and send back failing work with written fixes.
- **Data analysis.** SQL, Python, Snowflake, dbt and Tableau for cleaning, modelling and reporting.
